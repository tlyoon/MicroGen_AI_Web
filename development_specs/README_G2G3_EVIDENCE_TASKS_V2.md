# G2/G3 source-bound development task expansion (PR #675)

## Diagnosed exhaustion

The original source-bound independent-test catalog and all four original
G2/G3 technical requirements were consumed by 27 November 2026. The
persistent code author and promotion controller remained alive but had
no new eligible coding jobs. No source or academic acceptance gate was
thereby complete.

## Concrete approved next jobs

The protected GitHub main requirement manifest now supplies **six**
independent test specifications. Two new jobs concern genuinely missing
engineering checks at the academic QA boundary:

- `g2_two_pass_source_provenance_v1` establishes whether two distinct,
  attributed Selenium reviewer evidence records both match the original
  publisher source SHA. It never equates provenance with physics agreement.
- `g3_highlight_speech_timing_v1` checks the actual admissibility of
  element-anchored spoken-timing intervals and exposes overlaps or time
  overruns. It never equates timing metadata with decoded video or
  audio-quality acceptance.

The existing reviewed task factory converts each unmet, exact-G2/G3
checkpoint requirement into deterministic independent failing tests,
creates one unique source-commit Git worktree, and admits it exactly once
to the existing Selenium-only coder. Its publisher source/test SHA and
protected-main identity are checked before any model request. The
persistent controller subsequently promotes only a real candidate that
passes the independent test and both Windows CI gates, using existing
atomic guarded deployment. A previously claimed or uncertain Send
remains quarantined, not reissued.

## Bounded, honest limitation

This change restores **two additional real code-development tasks**,
not unbounded creative task invention. On exhausting all six reviewed
requirements, the controller must still report the exhaustion state,
not claim meaningful autonomous progress. An independent, authorized
source-review mechanism is necessary to create additional academically
meaningful requirements and ultimately close G2/G3. Science, spoken
content, pronunciation, visual synchrony, and second-subsection
acceptance remain unverified until real independent evidence exists.

Regression proof: `tests/test_development_g2g3_requirement_task_factory_v1.py`
includes false-positive model implementations for both new test oracles.
These must fail; no publication or paid model API is permitted.
