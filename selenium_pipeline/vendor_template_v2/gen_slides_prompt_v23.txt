PNG DIMENSION METADATA
======================================================================

PNG dimension metadata:
{png_dimension_json}

Use the PNG dimension metadata above when deciding how to include any figure in the LaTeX slides.

Mandatory figure rules:
- The JSON gives the true width and height of each PNG file.
- For every figure that is actually included, compute:
  aspect_ratio = width / height
- Preserve aspect ratio at all times.
- Never distort figures.
- Do NOT use a single unconstrained width-only or height-only strategy as the default.
- Use bounded-box sizing so that every included figure is constrained by both a maximum width and a maximum height:
  \includegraphics[width=...,height=...,keepaspectratio]{...}
- The purpose of specifying both width and height is NOT to distort the figure. It is to impose an upper bound in both directions while keepaspectratio preserves the original shape.
- Use the metadata only for figure sizing and layout decisions, never for inventing academic content.

Mandatory tightened figure sizing heuristics:
1. Figure-dominant single-column slide:
   - Use only when the figure is central to the slide and text is minimal.
   - Preferred sizing:
     \includegraphics[width=0.88\textwidth,height=0.56\textheight,keepaspectratio]{...}

2. Balanced figure-and-text single-column slide:
   - Use when the slide contains a short explanatory block or a few bullets together with a nontrivial figure.
   - Preferred sizing:
     \includegraphics[width=0.76\textwidth,height=0.42\textheight,keepaspectratio]{...}

3. Text-heavy slide with supporting figure:
   - Use when the figure is present only to support the explanation.
   - Preferred sizing:
     \includegraphics[width=0.62\textwidth,height=0.32\textheight,keepaspectratio]{...}

4. Two-column slide image:
   - Use when portrait/tall figures or side-by-side explanation clearly improve readability.
   - Preferred sizing inside the image column:
     \includegraphics[width=\linewidth,height=0.52\textheight,keepaspectratio]{...}

5. Tall portrait figure in two-column layout:
   - Preferred sizing inside the image column:
     \includegraphics[width=\linewidth,height=0.56\textheight,keepaspectratio]{...}

Aspect-ratio-guided layout rule:
- Use aspect ratio to help choose the slide layout class, not as the sole determinant of the raw image scale.
- Recommended interpretation:
  * aspect_ratio > 1.6:
    usually single-column, figure-dominant or balanced
  * 1.1 <= aspect_ratio <= 1.6:
    usually balanced single-column or two-column depending on text density
  * 0.8 <= aspect_ratio < 1.1:
    usually balanced or text-heavy depending on content density
  * aspect_ratio < 0.8:
    strongly prefer two-column layout first

Slide content density rule:
- Text must never overlap with figures.
- Figures must never extend beyond slide boundaries.
- If there are 4 or more bullets above a figure, do NOT use the figure-dominant box.
- If there are 3 or more bullets and the figure is nontrivial, prefer two-column layout.
- If text appears above the figure, prefer the balanced or text-heavy bounded box rather than the figure-dominant bounded box.
- If the figure remains too small to read under the bounded box, reduce text on that slide.
- If readability is still insufficient, split into two consecutive slides:
  1. concept/explanation slide,
  2. immediate figure-focused slide.
- Never compensate for poor readability by letting the figure exceed the bounded-box height limit.

Figure placement rule:
- Place figures as centered blocks, not inline with text.
- Preferred structure:
  \begin{center}
  \includegraphics[...,keepaspectratio]{...}
  \end{center}
- Or use the required figure wrapper defined later in this prompt.

Two-column layout rule:
- When a figure is tall (portrait orientation), when png_dimension_json recommends two_columns, or when side-by-side explanation clearly improves readability, Gemini should use a two-column Beamer layout.
- Strong triggers for two-column layout:
  1. aspect_ratio < 0.8
  2. figure_category = portrait_photo
  3. recommended_columns_layout = two_columns
  4. a balanced conceptual explanation plus a moderately sized figure fits better side by side than in vertical stacking
  5. the slide has 3 or more bullets and a nontrivial figure
- In these cases, prefer a structure such as:
  \begin{columns}
    \column{0.58\textwidth}
    concise explanatory bullets or short derivation

    \column{0.42\textwidth}
    \begin{center}
    \includegraphics[width=\linewidth,height=0.52\textheight,keepaspectratio]{filename.png}
    \end{center}
  \end{columns}
- For portrait scientist photos, prefer approximately 0.60\textwidth for text and 0.40\textwidth for the image column, with image height capped at 0.56\textheight.
- For balanced concept-and-figure slides with moderately wide or square figures, use two columns when it clearly improves readability and avoids overflow.
- If a figure is wide, keep a single-column layout unless the PNG metadata strongly indicates otherwise.
- Do not use two-column layout if it makes text or labels too small to read.
