## A single explicit already-prepared section

When, and **only when**, the immutable sourcebound receipts prove one original
section has full technical source review and recorded audio from the same
version, the following command may dispatch through the existing *strict*
PR485/PR472 multipart renderer (never the old static-slides.mp4 renderer):

```powershell
python -m selenium_pipeline.original_windows_release --campaign "PATH_TO_NEW_VERSIONED_CAMPAIGN" --section "8.4" --execute-prepared
```

The command **never auto-executes multiple sections**, never performs
model/TTS synthesis, never changes the already accepted publisher input, and
never authorizes student publication. Before rendering it reruns the existing
PR485 final source/material gate (necessary for a side-effecting operation).
Old blocked receipts are ineligible. New model responses, mapping evidence or
stage audio MUST start an explicitly new PR486 versioned campaign, not mutate
an accepted section receipt; altered hash/source files fail closed.

The command returns status 2 if explicit execution is blocked, status 0 for
read-only inspection or technically dispatched ready results; exceptions are
fatal and are not reinterpreted as success.
