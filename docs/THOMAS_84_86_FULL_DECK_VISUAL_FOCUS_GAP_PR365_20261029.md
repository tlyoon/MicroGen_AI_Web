## Follow-on deterministic template-graphics separation (same PR)

Direct inspection of real 17/11/13-page Beamer PDFs showed `get_drawings()` includes **16 identical common vector paths on every page**, mostly page backgrounds and header/footer decoration. The earlier `inspect_text_only` treated even these repeated template strokes as textbook figures and stopped on the first slide. New `beamer_template_vector_separator.py` checks exact drawing operations, rectangles, colors and line widths **across all deck pages** and waives only visually repeated header/footer/full-canvas template paths; no content-area vector or one-off figure is exempt. For a one-page deck no automatic recurring-template claim is made. The canonical text-only element gate now uses this stricter classification, but it still independently requires whole-narration source text, exact PDF text blocks, unique source page and geometry. No fabricated figure identity, source equation or word timing is permitted.

Independent re-audit stored private new **versioned** files `20261029_PR365B_TEMPLATE_FILTERED_SOURCE_FOCUS_8_{4,5,6}.json`. Each new deck has 16 repeated decorative vector paths per page; however all still contain extra page-specific graphics/image blocks and **nonverbatim original narration**, so all 41 slides correctly remain blocked from automated video production. This is a partial real defect repair, not a claim the finished multimedia contract is met. New regression `tests/test_beamer_template_vector_separator.py` demonstrates that identical decorative headers no longer block exact source text, but unique body figures and even identical body math strokes on every slide do block. Complete generated lecture files, previous reports and existing published candidate videos are preserved.
