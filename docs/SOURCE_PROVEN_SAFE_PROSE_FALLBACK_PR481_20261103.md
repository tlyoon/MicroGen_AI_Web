# PR481 — Zero-model, no-paid source-grounded prose fallback

The 41 original Thomas slides were rejected by the existing text-only mapping step because Beamer graphics and paraphrased academic narration are not verbatim source block matches. The main product integration is now complete through the compliant sourcebound video handoff, but semantic matching can remain unavailable when Gemini returns no valid output.

This new reusable fallback uses the PR475 immutable original source/author/script SHA-bound candidate worklists and the PR480 independently checked model-response schema. For each original utterance it identifies a UNIQUE directly corresponding nonmathematical visible PDF text element, requires independent substantive word overlap with an actual unmodified original textbook quote on a known source page, independently replays physical author element geometry, and rejects any low-margin or noncontiguous/ambiguous match. It never guesses equations, plus/minus signs, domain claims, figure/graph identities or composite panels, and NEVER authorizes audio synthesis or students' publication.

Run (native Windows, no LLM):
`python -m selenium_pipeline.rich_element_safe_prose_fallback --source-folder <original-lecture-folder> --checkpoint <old-accepted-rich-element-map-folder> --out-dir <NEW-outside-source-response-folder>`

The result is the SAME source-bound response format consumed by `rich_element_selection_compiler`. A fully independently verified text-only lesson can prepare a technical-only TTS request through the actual existing review bridge without making a new paid call; a genuine figure-rich lesson remains review-gated for its unmatched elements. Existing source/author/PCM/WAV and previously accepted scientific/visual proofs are never rewritten.

**Real Dell-115 frozen original Thomas result:** §8.4: 65 original utterances, 4 independently verified safe prose links, 61 unresolved; §8.5: 45 utterances, 3 safe links, 42 unresolved; §8.6: 57 utterances, 5 safe links, 52 unresolved. Total **12 safe prose links, 155 unresolved** across 167. This is STRICT source/author equivalence, not the previously broader 93 ambiguity count based only on heuristic rank margins. All original publisher PDF/author slide/script SHA checks passed, all 41 original slides retained, zero model/paid TTS calls. Physical response receipts live outside source in `%LOCALAPPDATA%\MicroGen_AI_Web_Checkpoints\20261103_PR481_DELL_REAL_SAFE_PROSE_NO_PROVIDER_FALLBACK`.

These 12 evidence-backed links can be reused when a model service responds, rather than reopened as a new scientific review. The remaining 155 require actual source-grounded model proposals and, for mathematical/figure claims, independent scientific verification; do not quietly weaken these gates to inflate automatic coverage. The first Gemini UI probe was submitted from the authenticated Dell-115 browser but produced no complete valid JSON; the local ChatGPT Chrome profile currently opens a guest login page and is not authenticated. Neither status is an authorization to create repeated prompts, call an API, synthesize audio or release a lecture.
